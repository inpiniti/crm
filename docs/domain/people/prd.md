# People — PRD

## 사용자 스토리

- 사람을 등록하고 회사·직책을 적는다.
- 인물 상세에서 이 사람이 요청한 업무 목록을 상태별로 본다. (핵심)
- 업무 등록 화면에서 이름으로 빠르게 검색해 요청자를 고른다.

## 기능

| 기능 | 설명 | 우선순위 |
|---|---|---|
| 등록/수정/삭제 | 이름, 회사, 부서, 직책, 연락처, 메모 | P0 |
| 상세: 요청 업무 목록 | Task 목록 (진행중 우선) | P0 |
| 이름 검색 (자동완성) | Task 폼에서 사용 | P0 |
| 요약 | 요청 건수, 진행 중, 마지막 요청일 | P1 |
