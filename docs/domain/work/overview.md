# Work — 개요

Task 를 처리하며 **실제로 한 일**의 기록. Task 애그리거트의 하위 엔티티이며 독립적으로 존재하지 않는다.

## 용어

- **Work (작업)**: "언제, 무엇을, 얼마나" 했는지 한 줄~한 단락. 예) "8/26 14:00 – 요구사항 정리, 2h", "고객 통화 후 범위 축소 합의".
- **worked_at**: 작업한 시각 (기록한 시각과 다를 수 있음).

## Task 와의 관계

- Work 는 반드시 하나의 Task 에 속한다. Task 를 옮기는 기능은 없다.
- Task 가 종료 상태(done/canceled)면 Work 추가 불가.
- Task soft delete 시 함께 soft delete.

## 불변 규칙

- 본문 필수 (빈 작업 기록은 의미 없음).
- `duration_min` 은 선택. 집계는 있는 것만 합산.
- 첨부파일 허용 (결과물, 캡처, 산출 문서).
