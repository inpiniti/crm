# Work — PRD

## 사용자 스토리

- 업무 상세 화면에서 바로 "오늘 한 일"을 한 줄 추가한다. (마찰 최소화 — 이게 안 되면 안 쌓임)
- 작업마다 걸린 시간을 적을 수 있고, 업무별/프로젝트별 합산을 본다.
- 결과물 파일을 작업에 붙인다.
- 날짜별로 "그날 무슨 작업을 했는지" 전체 타임라인을 본다. (Task 경계 무관)

## 기능

| 기능 | 설명 | 우선순위 |
|---|---|---|
| 추가/수정/삭제 | Task 상세 안에서 인라인 | P0 |
| worked_at 기본값 | 지금 시각. 날짜만 바꿔 과거 기록 가능 | P0 |
| 첨부파일 | 업로드/다운로드/삭제 | P0 |
| 소요시간 | 분 단위 입력, Task/Project 합산 표시 | P1 |
| 일자별 타임라인 | `/work?date=` 모든 Task 의 Work 를 날짜로 모아 보기 | P1 |
| 작업 유형 | `dev`/`meeting`/`call`/`doc`/`etc` (필터·집계용) | P2 |

## 필드

| 필드 | 타입 | 필수 | 설명 |
|---|---|---|---|
| task_id | FK | ✓ | |
| body | text | ✓ | markdown |
| worked_at | datetime | ✓ | 기본 = now |
| duration_min | int | | 소요 시간(분) |
| kind | enum | | 작업 유형 (P2) |

## 제외 범위

- 타이머(시작/정지) 없음. 끝나고 적는다.
- Work 끼리의 순서/의존 없음. 시간순 정렬만.
