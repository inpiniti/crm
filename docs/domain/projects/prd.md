# Projects — PRD

## 사용자 스토리

- 회사를 고르거나 "개인"으로 프로젝트를 만든다.
- 프로젝트 상세에서 업무 목록을 상태별로 본다. (진행중 / 대기 / 완료)
- 오래된 프로젝트는 보관(archive)해서 목록에서 숨긴다.

## 기능

| 기능 | 설명 | 우선순위 |
|---|---|---|
| 등록/수정/삭제 | 이름, 회사(선택), 설명, 기간, 상태 | P0 |
| 상세: 업무 목록 | Task 를 상태/마감일로 정렬·필터 | P0 |
| 보관(archive) | 상태 변경. 목록 기본 필터에서 제외 | P1 |
| 요약 | 전체/진행중/완료 Task 수, 최근 Work 일시 | P2 |

## 필드

| 필드 | 타입 | 필수 | 설명 |
|---|---|---|---|
| company_id | FK | | null = 개인 프로젝트 |
| name | string | ✓ | |
| description | text | | markdown |
| status | enum | ✓ | `active` / `archived` |
| started_at | date | | |
| ended_at | date | | |

## 제외 범위

- 첨부파일 없음.
- 마일스톤/서브프로젝트 없음. 필요하면 Task 로 표현.
