# Projects — 개요

업무(Task)를 묶는 단위. 회사 프로젝트일 수도, 개인 프로젝트일 수도 있다.

## 용어

- **Project**: 목적이 있는 업무 묶음. 예) "ERP 고도화", "회사 홈페이지", "개인 CRM 만들기".
- **개인 프로젝트**: `company_id` 가 null 인 프로젝트.

## 애그리거트

- 루트: `Project`
- Company 를 참조(nullable). Task 는 Project 를 참조한다.

## 불변 규칙

- 이름 필수. 같은 회사 안에서 이름 중복 불가 (개인 프로젝트끼리도 중복 불가).
- `company_id` 는 생성 후 변경 가능 (잘못 넣었을 때 옮길 수 있어야 함).
- 프로젝트를 `archived` 하면 신규 Task 생성 불가, 다른 프로젝트의 Task 를 옮겨 오는 것도 불가. 기존 Task 조회는 가능.
- Task 가 하나라도 있으면 삭제할 수 없다. 대신 archive 한다.
