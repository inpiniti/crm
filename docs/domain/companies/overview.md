# Companies — 개요

내가 다녔던(또는 다니는) 회사, 그리고 프리랜스/외주로 거래한 업체.
프로젝트와 사람을 묶는 최상위 컨테이너.

## 용어

- **Company**: 회사/업체. 재직 여부와 무관하게 "업무가 발생한 조직".
- **재직 기간**: 다녔던 회사라면 입사일/퇴사일. 거래처라면 비워둔다.

## 애그리거트

- 루트: `Company`
- 하위 엔티티 없음. Project/Person 은 Company 를 참조만 한다(별도 애그리거트).

## 불변 규칙

- 이름은 필수, 중복 허용 안 함(활성 기준).
- 참조하는 Project 나 Person 이 하나라도 있으면 **삭제할 수 없다**. 대신 퇴사일(`left_at`)을 채워 과거 회사로 정리한다. (삭제는 잘못 만든 빈 회사를 지우는 용도)
- 참조 없이 삭제(soft)한 회사는 목록에서 사라진다.
