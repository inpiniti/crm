# Companies — PRD

## 사용자 스토리

- 회사를 등록/수정/삭제할 수 있다.
- 회사 상세에서 그 회사의 프로젝트 목록, 소속 인물 목록을 본다.
- 회사 목록은 "현재 재직 중" → "과거" → "거래처" 순으로 정렬된다.

## 기능

| 기능 | 설명 | 우선순위 |
|---|---|---|
| 등록/수정/삭제 | 이름, 유형, 재직기간, 메모 | P0 |
| 상세: 프로젝트 목록 | 해당 회사의 프로젝트 (활성 우선) | P0 |
| 상세: 인물 목록 | 해당 회사 소속 Person | P1 |
| 상세: 업무 수 요약 | 프로젝트 합산 Task 수 / 진행중 수 | P2 |

## 필드

| 필드 | 타입 | 필수 | 설명 |
|---|---|---|---|
| name | string | ✓ | 회사명 |
| type | enum | ✓ | `employer`(재직) / `client`(거래처) / `other` |
| joined_at | date | | 입사일 |
| left_at | date | | 퇴사일 (null = 재직 중) |
| memo | text | | 자유 메모 |

## 제외 범위

- 첨부파일 없음.
- 주소/연락처 등 회사 프로필 필드는 두지 않는다 (필요하면 memo).
